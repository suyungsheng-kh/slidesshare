登入 Gemini 教育版

每次任務都從空白對話開始；先確認學校帳號，再上傳完整題目與來源。

01 教育部信箱

開啟 @go.edu.tw Gmail 並登入。

02 核對帳號

點右上角頭像，確認目前使用的學校帳號。

03 Gemini 入口

同一瀏覽器開啟 gemini.google.com，選相同帳號。

04 空白對話

點「新對話」，確認可以輸入文字或附加檔案。

若學校帳號顯示無法存取：記下錯誤訊息並詢問管理員。Gemini 教育版權限與 AI Studio API Key 分開；Key 不能替代教育版登入。

設定 Key，體驗出題

Key 用於教師端示範網站的直接生成；它不會自動提升題目品質，也不放進學生版 HTML。

01 AI Studio

開啟 Google AI Studio · API Keys，核對目前登入的帳號。

02 查看權限

可用時建立或選擇專案 Key；按校方及 Google 畫面完成設定。

03 連線測試

開啟 社會科素養題實驗室，只在 Key 欄位貼上並按「測試 API 連線」。

04 體驗出題

選地理、歷史或公民，填自己的材料與來源，按「使用 API 直接生成」。

無法建立 Key 或連線失敗：記錄無權限、用量、503 或網路錯誤；改按「產生並複製完整提示」，貼到新的 Gemini 對話完成同一任務。
